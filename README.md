The entry is one job title, 23 characters inside the gate's 60-character cap:

> **Last Words Fact Checker**

`main.py` copies `entry.txt` byte for byte to `/output/entry.txt`, so both
grading runs write identical bytes and the judge reads exactly the title
written here.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
