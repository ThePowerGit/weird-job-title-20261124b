# Last Words Fact Checker

**Entry:** Last Words Fact Checker

**Character count:** 23

**Limit:** 60 characters

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The script copies `entry.txt` byte-for-byte to the output directory
(`/output` by default, overridable with `MAKEFUN_OUTPUT_DIR`).
